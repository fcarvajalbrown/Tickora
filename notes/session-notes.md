- The project MCP server `tickora` is approved (`enabledMcpjsonServers` in `.claude/settings.local.json`) and was used live in chat 5.
- Both MCP eras are served. A request whose `_meta` carries `io.modelcontextprotocol/protocolVersion` is handled as 2026-07-28: -32022 with `supported` and `requested` for other versions, -32602 without `clientCapabilities`, results carry `resultType: complete` and serverInfo in `_meta`, and `server/discover` and `tools/list` carry `ttlMs: 3600000` and `cacheScope: public`. Without it, `initialize` selects legacy (2025-11-25, 2025-06-18, 2025-03-26, 2024-11-05 echoed, anything else gets 2025-11-25); other methods before `initialize` are -32602.
- Tools: `tickora_step` (inputs on the first stepped tick only, all inputs validated before any applies, ticks 1 to 100000), `tickora_state_hash`, `tickora_list_components`, `tickora_query` (limit default 100), `tickora_get_entity`, `tickora_reset` (seed as integer or decimal string). Hashes and seeds are decimal strings, because u64 above 2^53 loses precision in JavaScript. Unknown arguments are rejected; tool failures are `isError: true`; an unknown tool is -32602. Fx fields print via `to_f64` (1.2 shows as 1.1999999999534339).
